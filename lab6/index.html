Design Description

GDP amount is represented by rectangle area because larger areas allow users to compare the relative economic size of countries. GDP status is represented using color, allowing users to quickly distinguish countries whose GDP increased, stayed unchanged, or decreased. The first treemap uses the squarify algorithm, which produces rectangles with relatively balanced aspect ratios and can make individual countries easier to inspect. The second treemap uses the binary tiling strategy, which recursively divides the available space into two groups and therefore creates a different spatial organization. Although the two treemaps contain the same hierarchy and GDP values, their different segmentation strategies change the shape and arrangement of the rectangles. This comparison demonstrates how layout algorithms can affect the readability and spatial perception of hierarchical data.
