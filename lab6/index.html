Lab 6: Treemap Visualization

This visualization compares two treemap layout methods using country GDP data. Rectangle size represents GDP, while color represents GDP status.

Binary Treemap

GDP Status

Design Description

The treemap uses GDP to determine the size of each country rectangle. A square-root transformation is applied to reduce the visual dominance of countries with extremely large GDP values.

Green represents an increase in GDP, gray represents no change, and red represents a decrease.

The Squarify layout creates rectangles with more balanced aspect ratios, while the Binary layout recursively divides the available space into two groups.
