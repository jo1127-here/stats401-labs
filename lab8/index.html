DKU Bulletin: Semantic Exploration

Two coordinated overviews of course content, with searchable passages and nearest neighbors

1. Bulletin / Corpus Description

This project analyzes course descriptions from the Duke Kunshan University Bulletin. The corpus contains course-level text covering multiple academic subjects and departments.

Each course description is treated as an individual text passage. The corpus was cleaned and processed to support semantic embedding, topic modeling, and interactive exploration of relationships among courses and bulletin sections.

5. Reading the two overviews

The map shows relationships between individual course descriptions; the matrix summarizes how interpreted semantic topics span formal Course Subjects. These are two complementary overviews of the same corpus.

Topic names are human interpretations based on actual course titles and descriptions, not official Bulletin categories. For example, the mixed Language Learning & Practical Skills cluster contains language learning, writing, physical education, and practical courses.

The existing map uses all-MiniLM-L6-v2 embeddings and UMAP; KMeans assigns eight clusters in the original embedding space. Map position is approximate and does not determine neighbor ranking. Top 5 neighbors are computed separately using cosine similarity of normalized TF-IDF unigram/bigram vectors with English stop words removed. Selection excludes the passage itself and searches the full corpus.

Search and filters dim nonmatching map points. Matrix cells select subject-topic combinations. Clicking a passage highlights its matrix cell and five textual neighbors; clicking a neighbor opens that passage. The matrix retains the full corpus as context.
