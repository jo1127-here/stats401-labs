DKU Bulletin: Semantic Exploration

Interactive visualization of semantic structure and formal bulletin sections

1. Bulletin / Corpus Description

This project analyzes course descriptions from the Duke Kunshan University Bulletin. The corpus contains course-level text covering multiple academic subjects and departments.

Each course description is treated as an individual text passage. The corpus was cleaned and processed to support semantic embedding, topic modeling, and interactive exploration of relationships among courses and bulletin sections.

5. Semantic Findings

The embedding map shows several groups of semantically related course descriptions. Courses assigned to the same topic tend to form visible clusters, while some topics overlap where courses share similar terminology or interdisciplinary content.

  • Different semantic topics occupy different regions of the embedding space, suggesting meaningful variation in course descriptions.
  • Some clusters contain courses from related academic areas, while other regions show more mixed or interdisciplinary content.
  • The topic-section matrix provides another view of these patterns by showing how frequently each topic occurs within the Bulletin section.

6. Design Description

Each course description was converted into a high-dimensional semantic embedding. UMAP was then used to reduce these embeddings to two dimensions while preserving local semantic relationships. Each point in the embedding map therefore represents one course description.

The embeddings were grouped into eight semantic topics using clustering. The topics are represented by consistent colors across the embedding map and the topic-section matrix. The matrix uses cell intensity to represent the number of passages associated with each topic and Bulletin section.

Coordinated interaction supports exploration from multiple levels. Users can search for courses and filter the embedding map by section or topic. Clicking a point reveals detailed passage information, while clicking a matrix cell reveals the corresponding topic-section relationship. This allows users to move between individual course descriptions, semantic clusters, and aggregate corpus patterns.
