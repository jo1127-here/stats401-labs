Lab 4 — Cleaning Web Data

Tweet Sentiment and Tweet Length

This dataset contains 10,000 tweets from the Sentiment140 dataset. The raw tweet data was cleaned using Python and pandas by removing missing tweets and duplicate records, standardizing text, and creating tweet-level attributes such as tweet length and word count.

Sentiment was analyzed using a RoBERTa-based Transformer model. Each tweet was assigned a predicted sentiment category and a continuous sentiment score.

Number of records: 10,000

Short Analysis

This visualization shows how the distribution of RoBERTa-predicted sentiment varies across tweet-length groups. Each bar represents the percentage of tweets within a length group, divided into negative, neutral, and positive sentiment categories. Shorter tweets tend to show a relatively larger proportion of positive or neutral sentiment, while longer tweets contain a comparatively higher share of negative sentiment. However, the differences between groups are not extremely large, indicating that tweet length alone may not strongly determine sentiment. The stacked bar chart makes it easy to compare the relative proportions of the three sentiment categories across length groups. Overall, the results suggest a possible relationship between tweet length and sentiment, but additional variables would be needed to better explain the observed patterns.
