STATS 401: Data Acquisition and Visualization

Tweet Sentiment and Retweets

Short Analysis

This visualization uses a dataset containing at least 1,000 tweets. The raw data was cleaned using pandas by removing duplicate records, handling missing values, converting numeric variables, parsing dates, and standardizing text and categorical variables. Sentiment was estimated using a RoBERTa-based Transformer model. Each tweet was assigned a predicted sentiment category and a continuous sentiment score. The visualization compares tweet sentiment with the number of retweets. Each point represents a tweet, with the horizontal position representing retweets and the vertical position representing sentiment score. The visualization can be used to examine whether tweets with different sentiment levels receive different amounts of engagement. The sentiment predictions are model-generated estimates rather than ground-truth labels.
