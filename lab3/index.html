Lab 3: Web Data Acquisition

This dataset contains information about books collected from Books to Scrape.

The data were collected programmatically using Python, requests, and BeautifulSoup.

The scraper automatically navigates through 50 pages and collects 1,000 book records.

Each record contains the book title, price, rating, and page number.

Click a column heading to sort the table. Click again to reverse the sorting order.
