Lab 5: Interactive Network Visualization

This visualization shows a synthetic urban transit network containing 50 stations and 50 direct connections.

1. Node-Link Visualization

Node size: Daily passengers
Node color: District
Node shape: Station type
Link width: Travel time
Link color: Route type

2. Adjacency Matrix

Rows and columns represent stations. A filled cell indicates a direct connection between two stations.

3. Design Description

Node-Link Design

District is represented using node color so that stations belonging to the same district can be visually grouped. Daily passenger volume is represented by node size because larger circles indicate stations with higher passenger volume. Station type is represented by node shape to distinguish Local, Transfer, and Terminal stations.

Travel time is represented by link width, while route type is represented by link color. Users can drag stations, hover over stations to highlight their connections, and use tooltips to inspect station information.

Adjacency Matrix Design

Each row and column represents a station. A filled cell represents a direct connection. Cell opacity represents travel time, while cell color represents route type. Stations are ordered by district to make groups of stations easier to identify.

4. Network Questions and Findings

1. Which stations appear central in the network?

The node-link diagram is most useful because stations with many visible connections can be identified directly.

2. Which districts are strongly connected to one another?

The node-link diagram is useful because the colors of stations show district membership and the links reveal connections between districts.

3. Where are transfer or terminal stations located?

The node-link diagram is useful because station shapes identify different station types and their positions show where they occur in the network.

4. Which stations have high passenger volume?

The node-link diagram is useful because passenger volume is encoded by node size. Larger nodes indicate higher passenger volume.

5. Where are the longest direct travel-time connections?

Both visualizations can help answer this question. Thick links in the node-link diagram and darker cells in the matrix indicate longer travel times.

6. Are particular route types concentrated in particular parts of the network?

Both visualizations can help. Link colors show route types, while the district ordering of the matrix makes regional patterns easier to inspect.
