Lab 5: Interactive Network Visualization

This visualization shows a synthetic urban transit network containing 50 stations and 50 direct connections.

1. Node-Link Visualization

Node size: Daily passengers
Node color: District
Node shape: Station type
Link width: Travel time
Link color: Route type

2. Adjacency Matrix

Rows and columns represent stations. A filled cell indicates a direct connection between two stations. Cell opacity represents travel time, while cell color represents route type.

3. Design Description

Node-Link Design

District is represented using node color so that stations belonging to the same district can be visually grouped. Daily passenger volume is represented by node size because larger nodes indicate stations with higher passenger volume. Station type is represented by node shape to distinguish Local, Transfer, and Terminal stations.

Travel time is represented by link width, while route type is represented by link color. Users can drag stations, hover over stations to highlight their connections, and use tooltips to inspect station information.

Adjacency Matrix Design

Each row and column represents a station. A filled cell represents a direct connection. Cell opacity represents travel time, while cell color represents route type. Stations are ordered by district to make groups of stations easier to identify.

4. Network Questions and Findings

1. Which stations appear central in the network?

The node-link diagram is most useful for identifying central stations. Stations s7, s16, s18, s21, s25, s29, s31, s33, s34, and s38 each have three direct connections, which is the highest degree in the network. These stations therefore appear more central than stations with fewer connections.

2. Which districts are strongly connected to one another?

The adjacency matrix makes it easier to compare connections between district groups. The South and East districts have the largest number of direct connections between them, with 11 connections. The node-link diagram also shows several links connecting these two districts.

3. Where are transfer or terminal stations located?

Transfer and terminal stations are distributed across different parts of the network rather than being concentrated in one district. The node-link diagram makes these stations easy to identify through their different shapes. Several transfer and terminal stations are also located at highly connected parts of the network.

4. Which stations have high passenger volume?

The node-link diagram provides the clearest answer because passenger volume is represented by node size. Station s50 has the highest daily passenger volume, with 9,850 passengers, and therefore has the largest node size.

5. Where are the longest direct travel-time connections?

The node-link diagram is most useful for identifying long connections because travel time is represented by link width. The longest connection is s7-s31 at 16 minutes, followed by s18-s34 at 15 minutes and s29-s50 at 14 minutes. These connections also appear as higher-opacity cells in the matrix.

6. Are particular route types concentrated in particular parts of the network?

Route types are relatively evenly distributed across the network. There are 17 Express routes, 17 Shuttle routes, and 16 Metro routes. The different route types appear throughout the network rather than being concentrated in one particular district.
