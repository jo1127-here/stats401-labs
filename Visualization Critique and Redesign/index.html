Visualization Critique and Redesign

A critique and redesign of a Netflix content dashboard

Individual Project · D3.js Redesign

1. Original Visualization

The original visualization is a Tableau-style dashboard exploring Netflix's global content catalog across time, geography, genres, content types, and ratings. The dashboard combines several views, including time trends, geographic distribution, genre information, ratings, and title-level metadata.

The underlying dataset contains Netflix titles together with attributes such as title, content type, release year, age certification, runtime, seasons, country, genre, IMDb score, and IMDb vote count. The original dashboard is designed for a broad audience interested in understanding the composition and evolution of Netflix's catalog. Typical tasks include identifying trends in content production, comparing Movies and TV Shows, examining popular genres and certifications, and exploring geographic differences.

2. Redesigned Visualization

The redesign focuses on a more specific analytical question: How has the composition of Netflix's content catalog changed over time? The visualization uses a time-series view as the primary analytical component, while genre, certification, and country distributions provide supporting context.

3. Visualization Critique and Redesign Report

Original Visualization and Context

The original visualization is a multi-view dashboard based on a Netflix content dataset. It presents information about titles, release years, content types, genres, ratings, countries, and IMDb-related metadata. Its intended audience is a general audience interested in exploring Netflix's catalog rather than a specialized analytical audience. The dashboard supports several exploratory tasks, including comparing Movies and TV Shows, identifying temporal trends, examining genre distributions, and exploring the geographic composition of the catalog. Its broad coverage makes it useful as an exploratory overview, but it also creates challenges for users who want to answer one specific question efficiently.

Critique

The original dashboard has several strengths. First, it provides multiple perspectives on the same dataset. Time, geography, genre, and content type are represented together, allowing users to move between different levels of analysis. Second, the dashboard uses familiar graphical forms, such as maps, bars, and time-based charts, which lowers the learning cost for a general audience. These views also make it possible to discover patterns without requiring users to inspect the raw data directly.

However, the visualization has three important weaknesses. First, the large number of heterogeneous views creates weak visual hierarchy. Because several charts compete for attention, the dashboard does not establish a clear primary analytical task. Second, the stacked area representation of Movies and TV Shows makes direct comparison difficult because only the lower series shares a common baseline. A line chart provides a more precise comparison of changes over time. Third, the genre visualization treats multi-label genre combinations such as "Comedy, Drama" as categories. This makes it difficult to determine which individual genres are most common. The geographic view also emphasizes spatial distribution rather than precise ranking, which is useful for overview but less effective for comparing countries with similar values.

Redesign Rationale

The redesign makes three major changes. First, it establishes catalog evolution over time as the primary analytical task and places a two-line time series at the center of the visualization. This gives users a shared baseline and makes differences between Movies and TV Shows easier to compare. Second, the genre field is parsed into individual genre labels before aggregation. A title containing multiple genres therefore contributes to each relevant genre, producing a more interpretable ranking. Third, the supporting views use horizontal bars for certifications and production countries. Position along a common scale allows users to compare categories more directly than area-based encodings.

The redesign also introduces coordinated filtering by content type and release-year range. The same filters update all supporting views, allowing users to examine whether patterns change across different periods or between Movies and TV Shows. Hover interactions provide exact values without permanently displaying labels for every mark, reducing visual clutter while preserving access to detailed information.

Original vs. Redesign

Compared with the original dashboard, the redesign prioritizes analytical clarity over the number of views shown simultaneously. The original is stronger as a broad exploratory dashboard because it exposes many dimensions at once. The redesign instead provides a clearer visual hierarchy and makes temporal comparison the main task. The line chart improves comparison of content types, while the normalized genre and country aggregations reduce ambiguity in categorical comparisons. Interactive filtering also allows users to focus on smaller subsets of the catalog without introducing additional charts.

These improvements involve trade-offs. The redesigned visualization intentionally removes some of the title-level detail and geographic emphasis present in the original. It also remains dependent on the structure and completeness of the underlying dataset. In particular, country and genre fields may contain multiple labels per title, so their counts represent category occurrences rather than mutually exclusive titles. The redesign therefore improves the clarity of the selected analytical tasks, but it is not intended to replace every exploratory function of the original dashboard.
