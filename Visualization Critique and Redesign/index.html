Visualization Critique and Redesign Report

Original Visualization and Context

The original visualization is a Tableau dashboard created by Prathu10 that explores a dataset of Netflix movies and TV shows. The dataset contains metadata including title, content type, release year, runtime, genres, production countries, age certification, and IMDb score. The dashboard is intended for exploratory analysis of Netflix's catalog. Users can investigate genres, ratings, geographic distribution, content type, and changes over time.

Critique

One strength of the dashboard is that it provides several complementary views of the same dataset. Bar charts support categorical comparison, the map provides geographic context, and the time-series view provides temporal information. This makes the dashboard useful for broad exploration. A second strength is its consistent visual organization. Filters are placed near the top, while the larger charts occupy the main dashboard area, creating a recognizable structure for exploration.

However, the dashboard presents many different analytical questions with similar visual prominence. Genre, rating, geography, time, and individual-title information compete for attention, so there is no clearly established primary task. This weakens visual hierarchy and makes the overall analytical goal less explicit.

A second issue is the stacked area chart used to compare movies and TV shows over time. Although stacking communicates total volume, only the bottom series has a common baseline. The upper series must be interpreted through the difference between two boundaries, making direct comparison more difficult. A third issue occurs in the genre chart. Categories such as "Comedy" and "Comedy, Drama" are treated as separate labels. This makes it difficult to interpret the chart as a ranking of individual genres because multi-genre titles are not consistently represented. Finally, the proportional movie-versus- TV visualization relies on area, which is less precise for quantitative comparison than position or length.

Redesign Rationale

The first redesign decision is to establish a stronger visual hierarchy by making the temporal comparison the primary view. Supporting charts for genre, ratings, and countries are retained but given less visual prominence. This focuses the dashboard around a clearer analytical question.

Second, the original stacked area chart is replaced with a two-line chart. Both series use the same baseline and y-axis, allowing users to compare the number of movies and TV shows at each year directly. The redesign therefore changes the visual encoding from stacked cumulative height to position along a shared scale.

Third, the genre data are normalized before visualization. A title labeled "Comedy, Drama" contributes to both Comedy and Drama rather than being treated as a separate combined genre. The resulting horizontal bar chart provides a more interpretable ranking of individual genres. Finally, the redesign adds coordinated filters so that changes to content type and year update multiple views simultaneously.

Original vs. Redesign

The redesign prioritizes direct comparison and analytical focus over displaying as many independent views as possible. The two-line time series makes movie and TV-show trends easier to compare, while the normalized genre chart provides a clearer interpretation of genre frequency. Coordinated filtering also makes the relationships among views more explicit.

These improvements involve trade-offs. The redesign shows fewer dimensions simultaneously than the original dashboard, reducing breadth in exchange for a clearer hierarchy. In addition, changing the genre aggregation method changes the meaning of the genre counts, so the redesigned values should not be interpreted as identical to the original chart. Finally, the dataset represents a particular snapshot of Netflix-related metadata rather than a real-time Netflix catalog.
